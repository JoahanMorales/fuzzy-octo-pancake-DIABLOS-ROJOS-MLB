# Exploratory pitcher altitude sensitivity

These are aggregates from official local data, generated by
`python analysis/pitcher_sensitivity/run.py` (full fit, no raw records exported) with the production
Stuff+ v2 (count-neutral value + temperature, HACK-057), the same model as `reports/altitude_delta/`
(HACK-076). The league mean ΔStuff+ in `metadata.json` is −12.95 (production: −13.0).
`metadata.json` records the mode and cohort; all tables are exploratory,
in-sample globally prepared model estimates, not holdout or causal evidence.

- `pitchers.csv`: 1,455 pitcher-season entries; 1,277 ranking-eligible.
- `pitches.csv`: aggregates by anonymized pitcher-season pitch identity,
  with usage, weighted Δ contribution and modeled IVB/HB differences.
- `top15.csv` / `bottom15.csv`: 15 disjoint pitcher-season entries each,
  ranked by the empirical-Bayes altitude-proof index.

758 pitcher-seasons have an estimable shrunk observed model-quality split.
Missing observed estimates remain missing. The index is relative to the
season league effect: values above 100 mean a smaller loss or greater gain
than the league, even when absolute Δ remains negative. Individual ranges
are conditional posterior intervals and exclude model-fitting uncertainty.
Observed comparisons use Extreme Altitude versus No Altitude buckets, not
an assertion that every Extreme game took place at Harp Helú.

Full definitions, eligibility, limitations and input contract:
`analysis/pitcher_sensitivity/README.md`. Re-run the CLI to refresh the entire
set together; never splice figures from different model fits or seasons.
